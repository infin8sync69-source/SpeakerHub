# SpeakerHub

Android companion app for multi-speaker Bluetooth setups: checks whether the phone supports Auracast, manages speaker channel/delay settings and scenes, and opens the system Auracast settings.

## Install
Download `SpeakerHub-0.1.0-debug.apk` from the latest release, open it on an Android 12+ phone and allow "install unknown apps" when asked.

## Build
```
JAVA_HOME=<JDK 17> ./gradlew assembleDebug
```
